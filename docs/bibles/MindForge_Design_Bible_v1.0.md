# MindForge Design Bible

*The visual DNA for making invisible ideas recognizable.*

| **VERSION 1.0** | **VISUAL SYSTEM** | **LIVING DOCUMENT** |
|-----------------|-------------------|---------------------|

## 1. Purpose

MindForge transforms invisible ideas into visual artifacts that feel discovered rather than explained.

This document is the practical source of truth for color, geometry, contour fields, materials, typography, composition, and brand consistency. Use it before designing a thumbnail, scene, animation, website, title card, or reusable Three.js asset.

> **Visual north star**  
> A viewer should recognize a MindForge frame with the logo removed: violet cosmic depth, faceted geometry, glowing contour fields, impossible scale, and one clearly readable transformation.

### Brand promise

- Invisible concepts become physical, understandable worlds.
- Beauty creates attention; motion and symbolism create understanding.
- Every frame feels mysterious first, coherent second, and memorable last.

### The five-part visual DNA

| **Element**      | **Role**                                                           | **Recognition cue**                                                                  |
|------------------|--------------------------------------------------------------------|--------------------------------------------------------------------------------------|
| Faceted geometry | Turns concepts into symbolic objects and mechanisms.               | Clean silhouettes built from prisms, rings, lattices, planes, and particles.         |
| Contour fields   | Reveal pressure, information, force, memory, heat, or probability. | Thin luminous lines wrapping, bending, compressing, or rupturing around an artifact. |
| Cosmic gradients | Create the shared MindForge atmosphere.                            | Deep violet voids transitioning into purple, pink, rose, and rare warm sparks.       |
| Meaningful light | Shows understanding and state change.                              | Light spreads only when a concept activates, connects, or becomes clear.             |
| Impossible scale | Creates wonder and visual surprise.                                | A tiny symbol can become an endless structure within one transition.                 |

## 2. Non-negotiable laws

Consistency is created by rules, not by repeatedly using the same object.

1.  No literal realism by default. Use symbolic worlds unless reality is essential to understanding.
2.  One dominant idea per frame. Supporting details must strengthen that idea, not compete with it.
3.  Contour fields always communicate a hidden state; they are never decorative wallpaper.
4.  Color changes must mean something: state, intensity, risk, discovery, or transformation.
5.  Motion must reveal, compare, route, compress, divide, assemble, or transform. Avoid idle screensaver motion.
6.  At least one frame in every episode must be unmistakably MindForge and usable as a thumbnail.
7.  The logo is confirmation, not the source of recognition.

## 3. Color system

The palette should feel cosmic and alive without becoming neon chaos.

| **Swatch** | **Name**      | **Hex**  | **Meaning / Use**                                                        |
|------------|---------------|----------|--------------------------------------------------------------------------|
|            | Void Ink      | #080312 | Primary darkness and negative space. Never use pure black unless fading. |
|            | Deep Violet   | #1A0B38 | Mystery, depth, dormant systems, and shadow structure.                   |
|            | Forge Violet  | #6737FF | Primary brand energy, intelligence, and conceptual structure.            |
|            | Signal Pink   | #FF4FC8 | Transformation, attention, branching choices, and active change.         |
|            | Plasma Rose   | #FF7ABF | Emotional energy, saturation, and soft transitions.                      |
|            | Insight White | #FFF7FC | Truth, reveal, completion, and peak contrast.                            |
|            | Forge Spark   | #FFB36B | Rare discovery accent. Use under 5% of the frame.                        |

### Gradient recipes

| **Recipe**           | **Stops**                                 | **Use**                                           |
|----------------------|-------------------------------------------|---------------------------------------------------|
| Void field           | Void Ink → Deep Violet → Forge Violet     | Backgrounds, large negative space, openings.      |
| Transformation field | Deep Violet → Forge Violet → Signal Pink  | Core activations, decisions, reconfiguration.     |
| Revelation flare     | Signal Pink → Plasma Rose → Insight White | Final reveal, solved state, knowledge ignition.   |
| Rare discovery       | Forge Violet → Signal Pink → Forge Spark  | Special artifact, major surprise, premium accent. |

> **Color ratio**  
> Use roughly 70% void/deep violet, 20% violet/pink action, and 10% white or warm accent. A full-screen rainbow gradient is outside the system.

## 4. Shape language

Geometry is a vocabulary. A shape should carry a stable meaning across episodes.

| **Shape**       | **Default meaning**                        | **Typical behavior**                               |
|-----------------|--------------------------------------------|----------------------------------------------------|
| Sphere / orbit  | Energy, possibility, whole systems         | Pulses, attracts, emits fields, expands.           |
| Cube / tile     | Discrete information, matter, memory units | Stacks, routes, duplicates, fractures, sorts.      |
| Prism / shard   | Transformation, tension, decision          | Splits, refracts, rotates, pierces a field.        |
| Ring / gate     | Cycle, threshold, connection               | Opens, aligns, tunnels, synchronizes.              |
| Lattice / grid  | Rules, computation, structure              | Propagates signals, locks, overloads, reorganizes. |
| Contour surface | Invisible force or internal state          | Compresses, bends, ripples, tears, settles.        |
| Thread / beam   | Information flow, causality, relationship  | Routes, branches, knots, reconnects.               |

### Shape hierarchy

- Hero geometry: one large artifact with a strong silhouette.
- Mechanism geometry: 2–4 secondary systems that visibly affect the hero.
- Signal geometry: particles, contour lines, threads, and pulses that explain state.
- Atmosphere geometry: sparse distant forms for depth; never more detailed than the hero.

## 5. Contour field language

Contour lines are MindForge’s signature effect: a visible map of an invisible condition.

| **Field behavior**       | **Meaning**                                               | **Example**                                   |
|--------------------------|-----------------------------------------------------------|-----------------------------------------------|
| Wide, calm spacing       | Stable or low-intensity state                             | A cool processor before activity.             |
| Dense compression        | Heat, pressure, high probability, or overload             | Contours crowd around a computation core.     |
| Directional flow         | Information or causality has a path                       | Lines stream from input tiles into a lattice. |
| Curvature / gravity bend | An external force is changing the system                  | Contours fold around a heavy object.          |
| Interference pattern     | Two causes or signals interact                            | Memory and emotion overlap.                   |
| Rupture / discontinuity  | Failure, surprise, breakthrough, or impossible transition | A field tears as a new state appears.         |
| Settling / smoothing     | Resolution, understanding, equilibrium                    | Contours relax after the explanation.         |

> **Signature frame rule**  
> At least one hero object should deform, generate, or be revealed by a contour field in every MindForge episode.

## 6. Materials and light

MindForge materials should feel designed from concepts, not copied from real-world metal or plastic.

| **Material**  | **Appearance**                                                                  | **Best use**                           |
|---------------|---------------------------------------------------------------------------------|----------------------------------------|
| Contour Glass | Dark translucent volume with luminous field lines inside or across its surface. | Memory, probability, hidden structure. |
| Forge Ceramic | Matte, faceted dark body with soft violet edge light.                           | Hero artifacts and mechanisms.         |
| Signal Light  | Emissive pink-violet threads, points, or faces.                                 | Information, activation, links.        |
| Insight Core  | Near-white center with colored falloff and controlled bloom.                    | Revelation or solved state.            |
| Void Velvet   | Almost-lightless background surface that catches only rim light.                | Negative space, scale, silhouette.     |

### Lighting rules

- Use one narrative key light: it should point the eye toward the current idea.
- Use rim light to separate hero geometry from the violet void.
- Bloom belongs to active information and revelation, not every bright object.
- White light is earned. Reserve it for a discovery, answer, or irreversible transition.
- Avoid flat ambient light that reveals everything at once.

## 7. Composition and readability

A beautiful frame that cannot be read on a phone is not a successful Shorts frame.

| **Rule**              | **Application**                                                                                 |
|-----------------------|-------------------------------------------------------------------------------------------------|
| One-second read       | A viewer should identify the hero, its state, and the direction of change almost immediately.   |
| Asymmetric balance    | Prefer tension between a large hero and a smaller counter-element over perfect radial symmetry. |
| 70 / 20 / 10 priority | 70% visual focus on hero; 20% mechanism; 10% atmosphere and detail.                             |
| Depth layers          | Use foreground occlusion, hero midground, and simplified background to create scale.            |
| Negative space        | Leave clear breathing room for captions and to make contour motion readable.                    |
| Mobile contrast       | Test at thumbnail size. Thin lines may need thicker widths and brighter values on phones.       |

### Vertical safe zones (9:16)

- Keep critical text and faces of the hero artifact inside the central 80% width.
- Reserve the bottom 18% for platform captions and interface overlap.
- Reserve the top 10% for app chrome and visual breathing room.
- Place the most important reveal near the upper-middle, not at the extreme center-bottom.

## 8. Typography and labeling

Text is a quiet guide. The world should carry most of the explanation.

| **Element**            | **Style**                                                                 |
|------------------------|---------------------------------------------------------------------------|
| Question / hook        | Uppercase or title case, heavy weight, short line length, high contrast.  |
| Explanation            | Simple sentence fragments, medium weight, no more than two lines at once. |
| Artifact label         | ARTIFACT 0XX / NAME, small caps, generous tracking, violet or white.      |
| Brand lockup           | MindForge, restrained; pink spark or contour mark may accompany it.       |
| Numbers / measurements | Monospaced or tabular numerals when technical precision matters.          |

> **Typography principle**  
> Use bold text for the hook and thin, widely spaced labels for the universe. Do not let elegant typography weaken readability.

## 9. Thumbnail and title-card system

Recognition starts before the video plays.

- Use one artifact, one visible transformation, and no more than five words.
- Place a contour rupture, compression, or glow around the point of curiosity.
- Use violet-to-pink atmosphere consistently, but vary dominant shape and composition.
- Avoid generic science icons, photoreal computers, stock imagery, and cluttered diagrams.
- The thumbnail should promise a visual answer, not merely repeat the title.

## 10. Do / do not

The easiest way to protect a style is to define what does not belong.

| **Do**                                | **Do not**                                                    |
|---------------------------------------|---------------------------------------------------------------|
| Use a faceted symbolic artifact.      | Build a literal server room unless the contrast is essential. |
| Make contours respond to the concept. | Place random topographic lines over every surface.            |
| Use a controlled violet-pink palette. | Use every neon color to make the frame “futuristic.”          |
| Create one major transformation.      | Let objects rotate and glow without changing meaning.         |
| Use asymmetry and depth.              | Center a perfectly symmetrical machine for the entire video.  |
| Reveal with light and scale.          | Explain through paragraphs of on-screen text.                 |

## 11. Frame approval scorecard

A frame is approved only when it is recognizable, readable, and useful to the story.

| ☐ Recognizable without the logo         | ☐ Hero silhouette reads at phone size        |
|-----------------------------------------|----------------------------------------------|
| ☐ Contour behavior communicates a state | ☐ Color change has narrative meaning         |
| ☐ One clear focal point                 | ☐ No decorative motion without purpose       |
| ☐ Violet-pink atmosphere is controlled  | ☐ Text fits the safe zone                    |
| ☐ At least one unusual scale cue        | ☐ Frame could be used as a thumbnail         |
| ☐ Does not resemble a generic tech demo | ☐ Supports the exact concept being explained |

## Version 1.0 decisions

- Primary identity: faceted geometry + reactive contour fields + cosmic violet/pink gradients.
- Primary signature effect: contours visualizing hidden states around a hero artifact.
- Primary emotional sequence: mystery → activation → transformation → understanding.
- Primary brand test: recognizable with logo removed.
