# Reference narration assets

These MP3 files are reference narration for the current MindForge episodes. They
exercise the real Voice-bus / timeline / seeking path end to end. They are not a
provider lock-in: replace any file with a higher-quality human or TTS recording
at the same path, or point the semantic cue at a different URL.

Episode JSON references semantic `audio.voice.*` ids, never these paths directly.
